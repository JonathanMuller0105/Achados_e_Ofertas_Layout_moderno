# 🛍️ Achados E Ofertas - Landing Page de Ofertas

Uma landing page responsiva e moderna desenvolvida para atuar como vitrine de produtos afiliados (focada no ecossistema de ecommerce) e operações de dropshipping. 

O objetivo deste projeto foi construir uma interface de alta conversão, aplicando conceitos modernos de UI/UX design sem a dependência de frameworks externos, focando no domínio das linguagens base da web.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica visando acessibilidade e boas práticas de SEO.
* **CSS3:** Estilização avançada com foco em uma arquitetura limpa e de fácil manutenção.
* **FontAwesome:** Utilização de iconografia vetorial para melhorar a comunicação visual e o design.

## 🧠 Destaques Técnicos para Recrutadores

Este projeto foi desenvolvido com foco em demonstrar sólidos conhecimentos em Front-End raiz:

* **Design Responsivo (Mobile-First):** Utilização de *Media Queries* para garantir que a experiência do usuário seja perfeita tanto em dispositivos móveis (que representam a maior parte do tráfego em e-commerces) quanto em desktops.
* **Modern UI / Glassmorphism:** Aplicação de pseudo-elementos (`::before` e `::after`) para criar backgrounds com efeitos de *blur* dinâmicos, garantindo a legibilidade do conteúdo através de *overlays* translúcidos.
* **Layouts Modernos:** Domínio de **CSS Grid** e **Flexbox** para o alinhamento perfeito do *Hero Banner* e dos cartões de produtos na vitrine, garantindo que os elementos tenham o mesmo tamanho independente da quantidade de texto (utilizando `flex-grow`).
* **Sticky Header:** Implementação de cabeçalho fixo (`position: sticky`) com sombra difusa para melhorar a navegação do usuário sem prejudicar o espaço de tela.
* **Microinterações:** Efeitos de transição e elevação (`transform: translateY` e `box-shadow`) nos cartões de produtos para melhorar o *feedback* visual (Hover state) e a experiência de uso.
